Connect to your repo

This edits data.json directly in your GitHub repo via GitHub's API. Nothing here is stored anywhere but your own browser.

Before you paste a token here: create a fine-grained personal access token scoped to only this one repository, with Contents: Read and write permission and nothing else. Give it an expiry date (e.g. 90 days) rather than "no expiration". This token is stored only in this browser's local storage — it is never written to any file or committed anywhere. Anyone with access to this browser session could use it, so don't leave this page logged in on a shared/public computer, and use "Log out" when you're done.
